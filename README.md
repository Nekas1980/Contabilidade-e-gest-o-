# CT Contabilidade e Gestão

Website institucional e cartão de visita digital da **CT Contabilidade e Gestão**.

O projeto foi desenvolvido como uma presença digital leve, responsiva e orientada ao contacto com potenciais clientes, mantendo compatibilidade com alojamento estático como GitHub Pages.

## Objetivos

- Apresentar a marca de forma profissional e credível.
- Explicar de forma clara as áreas de contabilidade, fiscalidade e apoio à gestão.
- Facilitar o primeiro contacto com potenciais clientes.
- Ter boa experiência em computador, tablet e telemóvel.
- Manter uma solução simples, rápida e sem dependência de frameworks.

## Funcionalidades

- Navegação responsiva.
- Hero institucional com chamadas à ação.
- Secção de serviços.
- Proposta de valor orientada à gestão.
- Processo de acompanhamento em três etapas.
- Segmentação por tipo de cliente.
- Perguntas frequentes.
- Formulário de contacto que prepara automaticamente uma mensagem para WhatsApp.
- Contacto direto por WhatsApp e e-mail.
- SEO básico com meta description, Open Graph e dados estruturados Schema.org.
- Acessibilidade básica, incluindo skip link, labels e suporte a `prefers-reduced-motion`.

## Tecnologia

- HTML5
- CSS3
- JavaScript vanilla

Não existe backend nem base de dados. O formulário é processado localmente no navegador e apenas prepara o texto a enviar através do WhatsApp.
