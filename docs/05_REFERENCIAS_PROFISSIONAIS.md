# Referências Profissionais — CT Contabilidade e Gestão

Última verificação: 16 de setembro de 2026.

Este documento regista as fontes públicas utilizadas para orientar decisões de conteúdo e conformidade do projeto.

## 1. Ordem dos Contabilistas Certificados — publicidade

Fonte oficial:

- Ordem dos Contabilistas Certificados — Perguntas Frequentes, categoria “Profissão, Estatuto e Código Deontológico”.
- URL: https://www.occ.pt/pt-pt/faqs

A OCC esclarece atualmente que, apesar da revogação do anterior artigo específico sobre publicidade, os contabilistas certificados continuam sujeitos às normas e princípios do Estatuto e do Código Deontológico.

A comunicação da atividade deve ser:

- objetiva;
- verdadeira;
- compatível com os deveres deontológicos;
- compatível com o sigilo profissional;
- compatível com as regras legais de publicidade e concorrência.

A OCC alerta ainda para a necessidade de evitar publicidade propagandística, comercial ou de autoengrandecimento.

### Consequência para este projeto

O texto do website deve privilegiar:

- descrição factual dos serviços;
- explicação do processo de acompanhamento;
- informação clara sobre contacto;
- linguagem moderada;
- ausência de promessas de resultados.

Evitar formulações como:

- “garantimos menos impostos”;
- “aumentamos o seu lucro”;
- “somos os melhores”;
- “resultado garantido”.

## 2. Utilização do símbolo/logótipo da OCC

Fonte oficial:

- Ordem dos Contabilistas Certificados — Imagem Institucional.
- URL: https://portal.occ.pt/pt-pt/imagem-institucional

A utilização da imagem institucional da OCC está sujeita às condições definidas pela própria Ordem.

### Consequência para este projeto

Não adicionar logótipo ou símbolo da OCC ao website sem confirmar previamente que a utilização concreta é permitida.

Não usar o símbolo da OCC apenas para criar aparência de certificação ou associação institucional.

## 3. Estatuto e Código Deontológico

Fonte oficial:

- Ordem dos Contabilistas Certificados — Estatuto e Código Deontológico.
- Portal OCC: https://www.occ.pt/

O conteúdo profissional do website deve ser coerente com os deveres de integridade, rigor, independência, lealdade e sigilo profissional aplicáveis à profissão.

### Consequência para este projeto

O website é uma interface institucional. Não deve substituir a análise técnica de cada situação concreta nem divulgar informação de clientes.

## 4. CNPD e proteção de dados

Fonte oficial:

- Comissão Nacional de Proteção de Dados.
- URL: https://www.cnpd.pt/

A CNPD apresenta, nos seus próprios formulários, informação sobre:

- responsável pelo tratamento;
- finalidade;
- fundamento do tratamento;
- conservação;
- direitos dos titulares.

### Consequência para este projeto

Na versão atual, o website evita manter uma base de dados própria para os dados do formulário.

O formulário apenas prepara localmente uma mensagem que o utilizador pode decidir enviar por WhatsApp.

Se futuramente for criado um backend que armazene pedidos, deverá ser revista toda a informação de privacidade e segurança.

## 5. Livro de Reclamações

Fonte oficial:

- Livro de Reclamações Eletrónico.
- URL: https://www.livroreclamacoes.pt/

Antes da publicação definitiva, a profissional responsável deve confirmar quais as obrigações concretas aplicáveis à sua forma de exercício e atividade, incluindo a disponibilização de informação relacionada com o Livro de Reclamações quando aplicável.

Este projeto não deve presumir automaticamente essa obrigação nem inventar dados de registo.

## 6. Princípios adotados no website

Com base na natureza profissional do projeto, foram adotados os seguintes princípios:

1. **Objetividade** — descrever serviços sem prometer resultados.
2. **Verdade** — apenas publicar serviços e qualificações confirmados.
3. **Minimização de dados** — não armazenar informação quando não é necessário.
4. **Transparência** — explicar o funcionamento do formulário.
5. **Separação de responsabilidades** — desenvolvimento técnico e validação contabilística/profissional são responsabilidades diferentes.
6. **Rastreabilidade** — alterações importantes são realizadas através de Git e Pull Request.

## 7. Regra de manutenção

Sempre que existir uma alteração relevante em:

- Estatuto da OCC;
- Código Deontológico;
- orientação oficial da OCC;
- requisitos de proteção de dados;
- modelo de recolha de informação do website;

este documento e o conteúdo do site devem ser revistos.
